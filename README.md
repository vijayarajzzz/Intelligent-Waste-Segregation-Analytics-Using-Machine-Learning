Intelligent Waste Segregation Analytics Using Machine Learning
Overview

Intelligent Waste Segregation Analytics is an AI-powered system that uses Machine Learning and Computer Vision to detect, classify, and analyze different types of waste materials. The project helps improve waste management by automating segregation and providing useful analytics for recycling and environmental monitoring.

Features
Real-time waste detection and classification
Image processing using OpenCV
Machine Learning-based prediction
Waste analytics and visualization
Smart segregation recommendations
User-friendly interface
